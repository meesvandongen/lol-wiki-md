{{Documentation subpage}}

;Description
* {{t|Unofficial Champion data}} creates the [[:Category:Unofficial Champion data templates|hub page]] for '''unofficial''' [[champion]]s in {{tip|League of Legends}}.
* Champions are assigned various data in [[Module:UnofficialChampionData/data]], which can be retrieved by using {{t|Current Unofficial champion data}} and are listed in the "Parameters" table of the template.
* Within any specific champion's hub page, each parameter's value will be listed in the second column of the table.

;Setting up a new hub page
: Champion names should be typed as intended to be shown in-game and used across the wiki.
# Hub pages for new champions are created at the title:
#: <code>User:<Username>/<Champion name></code>
# Within that page, type:
#: <pre><nowiki><noinclude>{{Unofficial Champion data|Name of champion|Username}}</noinclude></nowiki></pre>
# Save the page.
# Create a new page created with the title:
#: <code>Unofficial:<Champion name></code>
# Within that page, type:
#: <pre><nowiki>#REDIRECT [[User:Username/Name of champion]]</nowiki></pre>
# Save the page.
