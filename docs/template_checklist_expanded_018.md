```
{{Documentation subpage}}
<!-- Categories and interwikis go at the bottom of this page. -->
;Description
: This template can be used to embed Riot Games' metagames on a wiki page. The games are embedded in most cases directly using files hosted on Riot's CDN, though some modified versions of the Unity WebGL player are hosted on the wiki itself (see [[MediaWiki:Gadget-metagames.js]]).

:The games do not load by default, and instead require the user to click a button to start them. This prevents people on bad connections being hit with several MBs of bandwidth on page load, as the games are quite large in size. They also consume a decent amount of browser memory. We do not have much control over when the browser garbage collects the unused memory after the game is unloaded.

;Usage
: To use this template, add <code><nowiki>{{Metagame|game=GAME_NAME}}</nowiki></code> to a page, where <code>GAME_NAME</code> is the name of the metagame you'd like to embed.

: The supported keys are (also listed in the [[MediaWiki:Gadget-metagames.js|gadget]]):

* <code>SBB_PILGRIMAGE</code> - Spirit Blossom Beyond - Pilgrimage Motion Comic
* <code>SBB_DEVOTED_SHRINE_MAIDEN</code> - Spirit Blossom Beyond - The Devoted Shrine Maiden Motion Comic 
* <code>WTN_BRINGER_OF_RUIN</code> - Welcome to Noxus - Bringer of Ruin 
* <code>WTN_FOURTH_PRINCIPLE</code> - Welcome to Noxus - The Fourth Principle 
* <code>WTN_DEMONS_HAND</code> - Welcome to Noxus - Demon's Hand minigame 
* <code>JFE_ACT1</code> - Jinx Fixes Everything - Act 1 (Arcade)
* <code>JFE_ACT2</code> - Jinx Fixes Everything - Act 2 (The Last Drop)
* <code>JFE_ACT3</code> - Jinx Fixes Everything - Act 3 (Firelight Base)
```

;Description
: Calculates terms in seconds, then displays them in MM:SS format.
: Minutes are not zero-padded, seconds are zero-padded.

;Syntax
: {{t|MinuteDisplay|first separate term|second separate term|third separate term|fourth separate term|fifth separate term}}
* Each parameter is the number of seconds in each term (positive or negative).
* Supports up to 5 separate terms; uses #expr parser function syntax.
* Only the first term is required, the rest are optional and default to 0.

;Example
<code><nowiki>{{MinuteDisplay|60|-50|10}}</nowiki></code> gives
{{MinuteDisplay|60|-50|10}}

<code><nowiki>{{MinuteDisplay|240|-30|35}}</nowiki></code> gives
{{MinuteDisplay|240|-30|35}}
