{{Documentation subpage}}
<!-- Categories and interwikis go at the bottom of this page. -->

'''Dts''' ('''d'''ate '''t'''able '''s'''ort) is used to correctly sort and display dates in a sortable table.

==What it solves==
Normally, for proper sorting, dates must be entered in YYYY-MM-DD format. However, that format does not conform to the [[wikipedia:MOS:DATE|Manual of Style]] for date display. This template automatically creates the hidden <code><nowiki><span style="display:none">1776-07-04</span></nowiki></code> for sorting purposes and then displays the date like this: '''July 4, 1776'''.

==Parameters==
===Input===
<nowiki>{{dts|date}}</nowiki>
*{{<code>dts|1776-07-04</code>}}
*{{<code>dts|July 4, 1776</code>}}
*{{<code>dts|4 July 1776</code>}}
