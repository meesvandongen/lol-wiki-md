;Usage
{{t|Patch box|Page|Section}}

This template automatically transcludes the specified ''section'' from the specified ''page'', and formats it within [[Template:Scroll box]] and adds a link to the ''page''.

''Section'' refers to a header element <code>==Example==</code>, and will include '''ALL''' content after that header element until the next header element. '''All''' includes any images, categories and templates. The headers have to be on the page itself - not added via a template.
