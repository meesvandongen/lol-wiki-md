;Description
:Displays two characters side-by-side with icons and their relationship status, formatted with emoji and tooltip styling.

;Syntax
:<pre>{{couple|Character1|Character2|type=RelationshipType|icon=IconName}}</pre>

;Parameters
* '''1 (Left character)''' = Name of the first character. Used for the icon and link.
* '''2 (Right character)''' = Name of the second character. Used for the icon and link.
* '''type''' (optional) = Relationship text to display between characters. Defaults to "Lovers".
* '''icon''' (optional) = Icon to display before the relationship text. Accepts the following:
** '''ring''' → displays 💍  
** '''broken''' → displays 💔  
** Any other value or omitted → defaults to ❤️
