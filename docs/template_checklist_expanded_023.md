```
{{Documentation subpage}}

;Description
This template is used to display delays that are affected by the game's tick rate ({{tt|precisely 0.033s|NOT 30 ticks per second.}} per tick). Things such as casts, damage, hits etc can only resolve at full integer frames. It is '''NOT''' used for tick rates in general, as their interaction with game ticks vary (e.g. {{ai|E|Karthus}} ticks with different delays since it carries over spent time waiting for the next delay, while {{ais|I|Sion}} repeating health cost rounds up to 8 game ticks every time).

There are two generated outputs: the visible text output, and the note embedded within its texttip. The displayed tooltip is generated by [[Template:Texttip]]. The displayed effective delay value is applied [[Template:Format decimal|default decimal formatting]].

The only argument is a time value and accepts any code that returns a number. If it is already the same as the game tick time, the template will not give the same clarification. It will give clarification regardless of the result if the argument is a mathematical operation.

;Usage
The abbreviated link <code>{{t|rutngt|Number}}</code> is used for brevity.

;Example
:<code>{{tl|rutngt|0.75}}</code> gives {{rutngt|0.75}}
:<code>{{tl|rutngt|0.035}}</code> gives {{rutngt|0.035}}
:<code>{{tl|rutngt|0.528}}</code> gives {{rutngt|0.528}}
:<code>{{tl|rutngt|0.66}}</code> gives {{rutngt|0.66}}
:<code>{{tl|rutngt|0.033*20}}</code> gives {{rutngt|0.033*20}}
:<code>{{tl|rutngt|1/4}}</code> gives {{rutngt|1/4}}

```
