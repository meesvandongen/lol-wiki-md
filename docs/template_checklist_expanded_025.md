{{Documentation subpage}}

;Description
: Creates special tabs for presenting ability numbers. Each tab has a label on a background, and text under it. If many tabs exist then buttons appear to let the reader change the tabs' view.
: Associated CSS: [[MediaWiki:Skill.css]] / Associated JS: [[MediaWiki:Common.js]]

;Syntax
: {{tl|st|label 1|text 1|label 2|text 2|label 3|…}}
: Each label–text pair constitutes one tab.
: If exactly two tabs exist, the view can be toggled by clicking on the entire label.
: If three or more tabs exist, adds buttons on either half for readers to navigate through the tabs.
: Can have up to 12 tabs.

;Example
: <pre>{{st|Magic Damage|{{ap|40|50|60|70|80}}}}</pre>
: <pre>{{st|Physical Damage Per Slash|{{ap|35|55|75|95|115}} {{as|(+ 50% '''bonus''' AD)}} {{as|(+ 50% AP)}}|Total Physical Damage|{{ap|70|110|150|190|230}} {{as|(+ 100% '''bonus''' AD)}} {{as|(+ 100% AP)}}}}</pre>
: <pre>{{st|Leveling name 1|Leveling values 1|Leveling name 2|Leveling values 2|Leveling name 3|Leveling values 3}}</pre>
:: ''Result''
: {{st|Magic Damage|{{ap|40|50|60|70|80}}}}
: {{st|Physical Damage Per Slash|{{ap|35|55|75|95|115}} {{as|(+ 50% '''bonus''' AD)}} {{as|(+ 50% AP)}}|Total Physical Damage|{{ap|70|110|150|190|230}} {{as|(+ 100% '''bonus''' AD)}} {{as|(+ 100% AP)}}}}

;Syntax
: {{t|sm2|File|champion|skin|card code|image&equals;}}
* First parameter is the name of the file, including the file extension. It is required.
* Second parameter is optional and places a card icon before the text component. Make sure the file exists at <code>Cardcode-circle.png</code> or <code>Cardcode Skin-circle.png</code>, e.g. [[:File:01DE042-circle.png]] or [[:File:03DE011 Ruined-circle.png]]. It is optional.
* Third parameter is the skin of the card. It is optional.
* Fourth parameter is the cardcode of the specific card, which may be used if the card has multiple forms with multiple voiceovers, like {{LoR|Grand Overseer Veigar}} or {{LoR|Spider Queen Elise}}. * A custom image can be added with the <code>image=</code> parameter. It is optional.

;Examples
: ''(unit + skin only)''
:{{tl|sm2/lor|VO_Lux_summon_01.ogg|Lux}} ''"The sun is shining, we should too!"''

<!-- Categories and interwikis go at the bottom of this page. -->
;Description
: This template is used to display the yield of certain units' experience bounty, such as minions, when it is being shared with a certain number of players.
: As of [[V14.10]], the default global modifiers for experience yield which are also used in this template are:
:* 95% for solo experience
:* 124%/2 for experience split to 2 players
:* {{fd|123.9}}%/3 for experience split to 3 players
:* 124%/4 for experience split to 4 players
:* 124%/5 for experience split to 5 players
:* {{fd|124.2}}%/6 for experience split to 6 players

;Syntax
: <code>{{t|sse|Number}}</code>
: (Required) A number for the base amount of experience to share.
: (Optional) The multipliers can be manually overwritten by using the <code>soloratio</code> and <code>sharedratio</code> parameters for the single player yield and multiple player yield, respectively.
: (Optiona) A suffix can be added to the numbers with the <code>key</code> parameter.

;Example
: <code>{{tl|sse|40}}</code>
