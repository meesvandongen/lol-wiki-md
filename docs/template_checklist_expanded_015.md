<!-- Categories and interwikis go at the bottom of this page. -->
;Usage
: Retrieves champion's abilities names and data from [[Module:ChampionData/data]] and champion ability data templates. Filters abilities according to the value and/or presence of a parameter. Formats the information for display in a list or table.

;Syntax
: <code>{{t|list of champion abilities|parameter|value|compare|noignorecase|format|edit|label}}</code>

;Parameters
: '''1/parameter''' - Optional; parameter to compare, defaults to showing all champion abilities
: '''2/value''' - Optional; value to compare to, defaults to empty string, use depends on compare parameter
: '''compare''' - Optional; how to compare the specified value to the data value, defaults to "equals", possible value:
* <code>equals</code>
* <code>exists</code>
* <code>exists and not empty</code>
* <code>exists and not equals</code>
* <code>exists and and not empty and not equals</code>
* <code>exists and and not empty and not contains</code>
* <code>contains</code>
: '''noignorecase''' - Optional; if true, filtering will be case sensitive, defaults to ignoring case
